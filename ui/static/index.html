Local-first MLOps

FLO-ML console

Train a churn model on your laptop the same way you will later train it on SageMaker. Data lives in a local AWS-shaped S3 (Floci). Every run is recorded in MLflow. No real AWS account. No cloud bill.

Same script

03 · track

MLflow

Params, metrics, and the model version land in the tracker on port 5000.

Local runs can be tagged Staging. Production is blocked until you point at real AWS.
